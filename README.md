# CS-330_SNHU

How do I approach designing software?

The design skills this project has helped me craft are all related to programming computer graphics as this is the first time I’ve done it. Additionally, learning how to create objects from shapes and choosing what shapes to use was great experience that will translate if I need to create another 3D scene.

For this project the planning phase was all about learning what 3D shapes were available to us and where to use them in relation to our scenes. From that point, the future weeks were about learning new skills such as camera setup, textures, lighting, materials and applying them to the project. The first thing I tackled in my scene was the pencil and it took a great deal of trial and error to get it right. To make passing coordinates easier, I created a helper function very early on that create shapes so I could make changes quickly all in one place.

These tactics will be very useful to me if I ever need to do graphics related programming using OpenGL or one of its variants. Using helper functions to keep things modular is an approach I often take when writing programs.

How do I approach developing programs?

Starting small and compiling/running often are 2 things, I did a lot in this course and do in real world development. Making small changes and testing them out makes debug much easier to the point where you can completely revert and go back to the last clean build. One thing that was a little different in debugging OpenGL is I often use print statements to help debug procedural coding projects but couldn’t here.

I used iterative development for this project. I created a desk, wall and one object that required multiple shapes during module 3 which gave me a taste of what that entailed. I don’t think I created any more objects until week 5 when I added the monitors with blank screens. There was lots of experimenting with coordinates, lighting and camera angles throughout the development process.

My development evolved such that objects became easier to create and place as I gained more experience. Additionally, as I learned more skills while navigating through the course, I was able to bring the scene to life using textures, lighting and materials. I also grouped the shapes used to create objects into helper functions for easier maintainability.

How can computer science help me in reaching my goals?

This course will be very helpful for future coursework and professionally if I ever need to do this flavor of programming again. I currently work in a development organization, more in a testing role but am working towards developing more production code and test automation. Keeping the programs modular, well commented, maintainable and easy to read is something that always translates.
